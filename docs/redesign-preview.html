Splyt, rebuilt around the gradient.

Three structures for the screen that replaces Home + Events. All three wear the same new chrome: the gradient header you pinned, a floating tab bar with rounded shoulders, filled icons carrying the active state, and the title sharing a row with a black pill action.

The bar drops from four tabs to three, because Settings moves into a sliding sheet and Events is absorbed by Home. Every remaining tab is a destination that exists nowhere else.

A trip is a date range, so time is the spine. The trip you're on sits open; everything else compresses to a row.
