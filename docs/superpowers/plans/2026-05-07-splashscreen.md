# Splash Screen Update Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default RN launch screens on iOS and Android with a branded splash: primary green `#2F6F57` background, centered white Splyt logo, "Splyt" text below.

**Architecture:** iOS uses `LaunchScreen.storyboard` (XML edit + new image asset in xcassets). Android uses a window-background theme (`SplashTheme`) backed by a layer-list drawable that references a pre-composed PNG (logo + text) generated by a Python script; `MainActivity.kt` switches back to `AppTheme` in `onCreate`.

**Tech Stack:** React Native 0.85.2, bare workflow, Python 3 + Pillow for asset generation, no new npm/gradle dependencies.

## Task 3: Create and run the Android splash asset generator

**Files:**
- Create: `scripts/generate_splash.py`
- Generated: `android/app/src/main/res/drawable/splash.png`

The script composites the white logo (200×200px) and "Splyt" text (72pt Arial Bold, white) onto a transparent canvas. The layer-list drawable centers this single PNG over the `#2F6F57` background.

- [ ] **Step 1: Create the scripts directory**

```bash
mkdir -p scripts
```

- [ ] **Step 2: Create scripts/generate_splash.py**

```python
#!/usr/bin/env python3
"""Generates android/app/src/main/res/drawable/splash.png.

Composites the Splyt white logo and bold "Splyt" text onto a transparent
canvas. The layer-list drawable (splash_bg.xml) provides the green background.
"""
import os
from PIL import Image, ImageDraw, ImageFont

LOGO_SIZE = 200
TEXT = "Splyt"
FONT_SIZE = 72
GAP = 24
PADDING = 48

script_dir = os.path.dirname(os.path.abspath(__file__))
project_root = os.path.dirname(script_dir)

logo_path = os.path.join(project_root, 'assets', 'branding', 'splyt-app-icon-no-bg-white.png')
out_path = os.path.join(
    project_root, 'android', 'app', 'src', 'main', 'res', 'drawable', 'splash.png'
)

logo = Image.open(logo_path).convert('RGBA')
logo = logo.resize((LOGO_SIZE, LOGO_SIZE), Image.LANCZOS)

font_candidates = [
    '/System/Library/Fonts/Supplemental/Arial Bold.ttf',
    '/Library/Fonts/Arial Bold.ttf',
    '/System/Library/Fonts/Helvetica.ttc',
    '/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf',
]
font = None
for fp in font_candidates:
    try:
        font = ImageFont.truetype(fp, FONT_SIZE)
        print(f'Font: {fp}')
        break
    except (IOError, OSError):
        continue
if font is None:
    font = ImageFont.load_default()
    print('Warning: using default font')

probe = Image.new('RGBA', (1, 1))
bbox = ImageDraw.Draw(probe).textbbox((0, 0), TEXT, font=font)
text_w = bbox[2] - bbox[0]
text_h = bbox[3] - bbox[1]

canvas_w = max(LOGO_SIZE, text_w) + PADDING * 2
canvas_h = LOGO_SIZE + GAP + text_h + PADDING * 2
canvas = Image.new('RGBA', (canvas_w, canvas_h), (0, 0, 0, 0))

logo_x = (canvas_w - LOGO_SIZE) // 2
canvas.paste(logo, (logo_x, PADDING), logo)

draw = ImageDraw.Draw(canvas)
text_x = (canvas_w - text_w) // 2
text_y = PADDING + LOGO_SIZE + GAP - bbox[1]
draw.text((text_x, text_y), TEXT, font=font, fill=(255, 255, 255, 255))

os.makedirs(os.path.dirname(out_path), exist_ok=True)
canvas.save(out_path, 'PNG')
print(f'Saved: {out_path} ({canvas_w}x{canvas_h}px)')
```

```

```

        android:exported="true">

            <action android:name="android.intent.action.MAIN" />
            <category android:name="android.intent.category.LAUNCHER" />
