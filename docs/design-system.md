# Splyt Design System

## Foundation

The app UI follows a restrained finance-dashboard visual language derived from the provided references:

- Deep ink: `#0C232A`
- Teal accent: `#29BFBD`
- Warm cream: `#FFFDDB`
- White surface: `#FFFFFF`
- Pale canvas: `#E6F0EE`

## Principles

- Elegant over decorative
- Minimalist over dense
- Consistent over experimental
- Calm numeric hierarchy over flashy interaction

## Component Guidance

- Cards use white or warm surfaces, soft radii, minimal borders, and subtle shadows.
- Active chips use deep ink fills. Inactive chips use outlines only.
- Primary actions use deep ink backgrounds with white text.
- Analytics colors stay muted and curated.
- Currency values should be the strongest typographic element within a section.
