Mobile App Style Guide

Overview

This style guide defines the visual and interaction system for a calm, healthcare-focused mobile application. The design emphasizes clarity, trust, and accessibility through soft colors, rounded components, and consistent spacing.

⸻

1. Color System

Primary Colors

* Primary Green: #2F6F57
* Secondary Green: #3E8C6A
* Gradient: Linear gradient using primary → secondary green

Neutral Colors

* Background: #F4F5F6
* Surface/Card: #FFFFFF
* Divider: #E5E7EB

Text Colors

* Primary Text: #1C1C1E
* Secondary Text: #6B6B6F

Semantic Colors

* Success: #4CAF50
* Warning/Error: #E74C3C

Accent Colors

* Blue: #3B82F6
* Green Accent: #22C55E

⸻

2. Typography

Font Family

* iOS: SF Pro
* Cross-platform: Inter

Type Scale

* Large Header: 28–32pt, Bold
* Section Title: 20–22pt, Semibold
* Card Title: 16–18pt, Semibold
* Body Text: 14–16pt, Regular
* Caption: 12–13pt, Medium

Guidelines

* Line height: 1.3–1.5x font size
* Use bold sparingly
* Maintain high contrast

⸻

3. Spacing System

Base Unit

* 8pt grid system

Spacing Scale

* XS: 4pt
* SM: 8pt
* MD: 16pt
* LG: 24pt
* XL: 32pt

Layout Rules

* Screen margin: 16pt
* Card padding: 16–20pt
* Maintain consistent vertical rhythm

⸻

4. Layout Principles

* Use card-based layouts
* Prioritize whitespace and readability
* Avoid visual clutter
* Align elements consistently on grid

⸻

5. Components

Cards

* Corner radius: 16–20pt
* Background: White
* Shadow:
    * Y offset: 4–8
    * Blur: 16–24
    * Opacity: 5–10%

Buttons

Primary Button

* Background: Dark/Black or Primary Green
* Text: White, Bold
* Height: 48–52pt
* Radius: 20–24pt

Secondary Button

* Outline or light gray background
* Same radius and height as primary

Badges / Pills

* Fully rounded
* Padding: 6–10pt horizontal
* Colors:
    * Green: Active
    * Blue: Pending
    * Red: Risk

⸻

6. Navigation

Top Navigation

* Minimal layout
* Left: App title/logo
* Right: Notifications + Avatar
* Optional gradient background

Bottom Tab Bar

* 4–5 tabs max
* Icons with labels
* Active state emphasized
* Slight elevation

⸻

7. Notifications

* Display inside cards
* Include:
    * Icon (colored background)
    * Title (bold)
    * Supporting text
    * Timestamp
* Indicators:
    * Red for urgent alerts
    * Blue dot for unread

⸻

8. Modals & Bottom Sheets

* Corner radius: 24pt (top corners)
* Includes drag handle
* Dimmed background overlay

Structure

1. Header (title + close)
2. Content
3. Actions (buttons)

Behavior

* Slide up animation
* Lightweight and dismissible

⸻

9. Media Components

* Rounded video containers
* Overlay playback controls
* Minimal UI chrome

⸻

10. Avatars

* Circular
* Size: 32–48pt
* Optional status indicator

⸻

11. Data Visualization

* Rounded bar charts
* Soft green palette
* Minimal gridlines
* Subtle labels

⸻

12. Icons

* Outline style (SF Symbols inspired)
* Stroke: 1.5–2px
* Rounded edges
* Consistent weight

⸻

13. Motion & Interaction

* Duration: 250–300ms
* Easing: Smooth (ease-in-out)
* Subtle micro-interactions
* Avoid aggressive animations

⸻

14. UX Principles

* Calm and reassuring tone
* Avoid alarm unless necessary
* Focus on:
    * Trust
    * Safety
    * Simplicity
    * Accessibility

⸻

15. Accessibility

* Ensure high contrast text
* Large touch targets (min 44pt)
* Support dynamic text sizing
* Avoid reliance on color alone

⸻

16. Platform Guidance

* Follow Apple Human Interface Guidelines
* Maintain consistency across screens
* Optimize for readability and ease of use

⸻

Summary

This design system promotes a clean, modern, and human-centered interface optimized for healthcare and monitoring applications. Consistency in spacing, typography, and component design is critical for maintaining trust and usability.
