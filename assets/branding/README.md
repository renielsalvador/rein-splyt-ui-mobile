# Splyt Branding

This folder contains the current brand assets for Splyt.

- `splyt-logo-mark.svg`: transparent logo mark for product surfaces and docs
- `splyt-app-icon.svg`: rounded-square app icon master for launcher/export work

The current mark is based on:

- a rounded teal square for a compact app-icon silhouette
- a white receipt illustration to represent shared expense tracking
- a diagonal split through the receipt to reinforce the "split" concept
- coins and ledger bars on the left side to suggest costs and line items
- an `S` with additional ledger bars on the right side to tie the mark back to Splyt

Recommended next step:

- Export platform-specific app icon sizes from `splyt-app-icon.svg`
- Replace the temporary `S` text badges in the UI with `splyt-logo-mark.svg` where branding is needed
